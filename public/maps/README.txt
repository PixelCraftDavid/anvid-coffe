Ixmiquilpan reference map data

ixmiquilpan.json contains derived OpenStreetMap geometry. The data is available
under the Open Database License (ODbL) 1.0:
https://opendatacommons.org/licenses/odbl/1-0/

Attribution: © OpenStreetMap contributors
https://www.openstreetmap.org/copyright

Source extract, obtained 2026-10-23:
https://api.openstreetmap.org/api/0.6/map?bbox=-99.235,20.477,-99.17,20.508

The JSON includes its projection, origin, bounds and source. It is generated by
scripts/build-ixmiquilpan-map.mjs from the local .osm extract. Roads, parks and
waterways are grouped into five static SVG paths in the interface. No external
tile requests, geolocation tracking, customer data or API keys are involved.

The UTVM reference point is based on the public university listing from Mexico's
Sistema de Información Cultural:
https://sic.gob.mx/ficha.php?table=universidad&table_id=22
The center point represents a sales area, not a stand or a customer's location.
